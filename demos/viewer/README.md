# Browser demos

From the repository root, install dependencies and start live physics:

```bash
npm --prefix demos/viewer ci
npm --prefix demos/viewer run live
```

Open **http://127.0.0.1:5173/live.html**. The launcher builds and runs the Rust CPU
server and Vite; Ctrl+C stops both. Requires the repository's Rust toolchain,
Node.js 22.12 or newer and a WebGL browser. See the
[live demo guide](../../docs/live-demo.md) for controls and alternate ports.

For recording playback only, run `npm --prefix demos/viewer run dev` and open
**http://127.0.0.1:5173/**. Choose **Open recording** to load a JSON generated by the
[pick-and-place example](../../docs/examples.md#pick-and-place-recording).

`npm --prefix demos/viewer run build` builds both pages. A static build still needs
the Rust server and a WebSocket proxy for live physics. See
[Contributing](../../CONTRIBUTING.md#browser-checks) for browser tests.
